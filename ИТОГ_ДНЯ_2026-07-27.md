### Почему curl всё-таки был нужен

Боевые данные живут на Render. В репозитории лежал снимок, **отставший на
7 недель и 182 сделки**. Прямого доступа к вашему API у меня нет — песочница с
ограниченной сетью. Так что километры curl были единственным каналом.

**Теперь не будут.** Сделано два скрипта:

- `scripts/collect_telemetry.ps1` — 21 эндпоинт одной командой в
  `analytics_24h/telemetry_<дата>.json`;
- `scripts/read_telemetry.py` — сразу превращает файл в сводку и, главное,
  `--export-traj` извлекает **траектории сделок** в формат калибровочных
  скриптов. Именно на траекториях строится вся калибровка выходов, и раньше их
  приходилось переносить вручную.

Новый цикл работы:

```powershell
$env:TOKEN="<OWNER_API_TOKEN>"; $env:API="https://robot-api-1rgi.onrender.com"
.\scripts\collect_telemetry.ps1
git add analytics_24h && git commit -m "telemetry" && git push
```

Дальше я читаю файл напрямую — без копирования в чат.
